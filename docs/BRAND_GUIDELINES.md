# JSO — Visual Identity Guidelines

## Official identity

The JSO website and future mobile application use the club crest as the primary brand mark.

**Club:** Jeunesse Sportive de Oudhref  
**Founded:** 1973  
**Primary colors:** navy blue and gold

## Brand assets

- `public/jso-club-mark.svg` — primary digital crest
- `public/favicon.svg` — compact browser/app icon
- `public/jso-platform-overview.svg` — platform architecture/marketing visual

## Colors

| Token | Value | Usage |
|---|---|---|
| JSO Navy | `#071A3A` | Header, footer, backgrounds |
| JSO Gold | `#F4C542` | Crest, highlights, CTAs |
| JSO Blue | `#1769E0` | Links, active states |
| Paper | `#F6F8FC` | Main page background |
| Ink | `#0B1730` | Primary text |

## Usage

The crest should remain recognizable at every size. Prefer the full crest for:

- website header
- homepage hero
- footer
- admin login
- mobile application splash screen
- app icon
- social/share cards

Avoid:

- changing the brand colors arbitrarily
- stretching the crest
- placing the crest on busy backgrounds without sufficient contrast
- replacing the crest with generic initials when the official mark is available

## Mobile identity

The mobile application should use the same visual system as the website:

- JSO crest as app icon
- navy navigation
- gold primary actions
- blue interaction states
- white/paper content surfaces
- same typography hierarchy
- same Match Center, News, Media and Team concepts

The mobile app is planned with React Native + Expo and will consume the existing .NET 10 REST API.
